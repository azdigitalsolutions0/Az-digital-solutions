# AZ Digital Solutions — New Website

A fresh responsive static website built with HTML, CSS and JavaScript.

## Included
- Premium dark navy + champagne gold visual system
- User-supplied round AZ Digital Solutions logo
- Animated hero/orbit treatment, scrolling ticker, reveal-on-scroll effects and hover states
- 11 service categories with enquiry-only calls to action
- About, process, FAQ, contact form and WhatsApp enquiry flow
- Instagram link, SEO metadata, favicon and mobile navigation
- Responsive mobile, tablet and desktop layouts
- Reduced-motion accessibility support

## Publish with GitHub Pages
1. Extract this ZIP on your device.
2. Upload all files and folders inside the extracted folder to the root of your existing GitHub repository (not the ZIP itself).
3. Keep the `assets` folder and its files together.
4. Commit changes to the `main` branch.
5. Open repository **Settings → Pages**.
6. Choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
7. After GitHub Pages finishes deploying, open the published URL and refresh once.

## Contact and configuration
Business contact information is in `index.html` and the WhatsApp link uses the configured business number. Update it only if the official contact details change.

## Important
- The enquiry form opens a prefilled WhatsApp message; it does not submit to a server or store form data.
- No prices are shown; visitors are invited to enquire.
- Insurance, loans and financial products depend on provider terms, eligibility, permissions and applicable rules. No approval, returns or outcomes are guaranteed.
- Mutual fund-related promotion or services should be displayed only where the required registration/authorisation is in place.
- Replace any future portfolio placeholders with genuine approved work before publishing.

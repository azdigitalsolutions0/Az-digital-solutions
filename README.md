# AZ Digital Solutions Website

Responsive static website built with HTML, CSS and JavaScript. Ready for GitHub Pages.

## Before publishing
1. Open `assets/config.js`.
2. Add your WhatsApp number in international format using digits only (India example: `919876543210`).
3. Add your official business email and confirm the location.
4. Add social media links if needed.
5. Verify all services and partner-related wording before going live.

The enquiry form opens WhatsApp with a pre-filled message. It does not send messages automatically.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `az-digital-solutions`.
2. Upload all files and folders inside this ZIP to the repository root (do not upload only the ZIP file).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish. Your live URL will appear in the Pages section.

## Important
- This is a static website; no server/database is included.
- Do not publish passwords, customer information, API secrets or confidential partner material.
- Insurance, loans, credit cards and investment products depend on partner permissions, provider terms, eligibility and applicable regulations. No approval, returns or claims are guaranteed.
- Mutual fund-related promotion/distribution must only be undertaken where required registration/authorisation is in place.
- Update legal disclosures, prices, service availability and contact details before publishing.
